# Origin — one stick, two births

Inventor: LowC (Carlos Rodrigues).

Problem: a host that requires two separate USB keys to mint one security key.

Invention: a single USB that can present two identities by changing mode through physical handling.

Sequence:

1. Seat the stick. Create key identity A.
2. Double-plug (remove + immediate reseat as the flip command) to enter B-mode.
3. Record key identity B on the same stick.
4. The host treats A and B as two different devices because the presence language made them so.

IPP is the name of that language. Plug Key is the hardware that performs it.

This is not "two partitions." This is not "a file named key2.txt." The second birth is a mode change signaled by inserts, removals, and timing.
