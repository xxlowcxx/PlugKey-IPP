# Plug Key and IPP

Two projects share this repo. They are not the same program.

| | Plug Key | IPP |
| --- | --- | --- |
| What it is | A USB that talks by how many times it is inserted. | Insertion Plug Presence. The insertion language. Its own idea and IP layer for privacy and secure exchange. |
| Started as | A second insertion on one stick. It became an emergency language for a failed or locked-out system. | The insertion language created for Plug Key. The value stretches past the stick. |
| What it is not | IPP. A password file. A bypass. | The USB. |
| Status | Inventory and owned-hardware design. | The page is the record until the insertion language has a body. |
| Owner | LowC. Toolaid. | LowC. Toolaid. |

A physical insertion is not a setting a program can mute. That sentence belongs to Plug Key.

IPP is Insertion Plug Presence, the insertion language. IPP is not the stick.
